# Advanced-Excel-Employee-Database-Management
A professional Employee Database Management project built using Advanced Microsoft Excel. Includes employee records, salary management, department-wise analysis, data validation, drop-down lists, VLOOKUP, IF, COUNTIF, SUMIF, conditional formatting, sorting, and filtering for efficient HR data management and reporting.
Advanced Excel – Employee Database Management

Project Overview

This project focuses on building a professional Employee Database Management System using Microsoft Excel. It organizes employee information, simplifies HR data management, and demonstrates advanced Excel techniques for data analysis and reporting.

Project Objectives

- Maintain organized employee records.
- Manage employee salary and attendance information.
- Track department-wise employee details.
- Analyze employee performance.
- Improve data accuracy using Excel features.

Dataset Details

The employee database includes the following fields:

Column| Description
Employee ID| Unique employee identification
Employee Name| Full name of employee
Gender| Employee gender
Department| Assigned department
Designation| Job position
Joining Date| Date of joining
Salary| Monthly salary
Attendance| Attendance percentage
Performance Rating| Employee performance score
Employment Status| Active or Inactive
